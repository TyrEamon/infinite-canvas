# 待测试

- 画布内新增独立“Agent 聊天”节点：从底部工具栏、空白处新建菜单或图片/文本的拉线菜单创建；直接连图片、全景图、文本后选已配置的自定义模型聊天，侧边栏 Agent 不参与。节点保留完整可见对话，发给模型的上下文可选最近 4/8/16 轮；连接内容在每次发送时快照，旧轮图片不重复附加，参考图片按整轮 3 MiB 预算压缩，过大或模型不支持时显示错误而不静默省略。视频/音频不直接连接，视频可在右键菜单截取首/中/尾/当前帧作为图片连接。验证文本问答、图像分析、多图、模型切换、增删连线、替换来源图片、长对话、刷新中断、停止、复制节点空历史、删除后撤销恢复历史、导出导入和主题/缩放交互；顶部“独立聊天”标题栏应能拖动节点，模型选择、消息滚动和输入框应保持原有操作；聊天运行时收起或取消选中节点不应中断请求。此项尚未执行构建或人工测试。
- 画布新建图片节点与生图配置节点：同一浏览器按渠道和模型沿用上次提交的图片比例；首次使用默认 `auto`，Codex ImageGen 单独记忆。从图片节点拉线新建图片或生图配置节点时，优先预填来源节点的模型、渠道、比例、质量、张数及工作流；普通上传图片无生成设置时沿用当前模型和本地记忆。Codex 生成的结果节点应保留 Codex 标记，继续拉线仍选中 Codex ImageGen。从视频节点拉线新建视频时优先预填来源节点的模型、比例、分辨率和秒数；来源缺项时才用该模型的本地记忆或全局默认。普通新建视频节点按渠道和模型沿用上次提交的设置。以上继承仅在创建时预填，之后增加其他图片或视频连线不改参数；手动改过的单项在切换模型时保持不变，未手动改的比例可切换到新模型的记忆值。确认刷新后记忆仍在、另一浏览器不共享，旧节点设置不被批量修改。
- 原生 DashScope 渠道：在“本地模型渠道”选择“阿里云百炼 DashScope”，填同地域的业务空间 Base URL（以 `/api/v1` 结尾）及 Key，选择 `wan3.0-video` 或 `wan3.0-video-prime`。分别验证画布文生视频、参考图片、首尾帧、参考视频/音频、视频迭代的创建任务→轮询→结果回填；检查 480/720/1080P、比例、2–30 秒/智能时长、声音、水印，以及万相失败原因显示。结果 URL 仅短时有效，应确认画布自动转存成功。首尾帧与普通参考混用、不可公网访问的视频/音频须在提交前明确拒绝。本地渠道未登录时浏览器直连可能受上游 CORS 限制；登录后应走画布后端代理。模型列表为官方两种万相 3.0 视频模型预设，不代表该 Key 已开通权限。此渠道与浏览器网页桥接互不依赖，尚待使用新 Key 实际测试。
- 原生 DashScope 视频节点选择 `wan3.0-video` 或 `wan3.0-video-prime` 时显示“AI 优化”；分别测试当前文本模型 API 和本地 Codex，只返回文字优化稿并打开审核弹窗。确认取消不会提交视频；“使用原文生成”和“采用并生成”均走原生 DashScope API 而非浏览器桥接，节点保留实际选用的提示词和原有视频设置。未配置文本模型、Codex 未连接或优化失败时应显示原因。
- 本地无限画布 × 通义万相浏览器扩展：重新加载扩展并刷新画布、万相标签页；从视频节点选择“通义万相网页”生成，确认提示词及关联素材送入万相、自动提交后能显示任务 ID，且仅将该 ID 的唯一视频自动回传对应节点。用含多个历史视频的万相页面验证不会误取旧视频；生成期间再发起第二条任务应明确拒绝覆盖。检查任务缺少 ID、返回多个视频、下载失败时停止自动回传并显示原因；手动扫描仍可使用但需用户自行确认视频。另验证无参考图、多个参考素材、单文件超过 200 MB、页面控件变化及跨域视频读取失败时的提示。任务 ID 自动回传尚待登录页面实测。
- 万相网页模型的视频节点设置打开时从万相视频页读取当前模式的分辨率、画面比例、智能/秒数选项；确认无 21:9 等网页未提供的误导性按钮、可选时长不再从通用视频的 6 秒起，网页未打开或选项读取失败时只提供“网页当前”并显示原因。切换万相模式后重新打开设置应刷新选项；选择 3 秒等具体时长时，扩展应操作万相的数字输入框或滑杆并核对页面已切换，不能再把找不到下拉选项误报为“不支持”。网页模式不支持或控件变化时停止提交并在节点显示原因。已有视频迭代生成的新节点应沿用本轮设置。含参考视频时验证时长限制会被明确报错，不得静默改成网页默认值。万相任务 FAILED、创建请求报错或完成后仅返回“抱歉，我无法回答这个问题”等文本时，画布节点及提示应显示万相原话；若页面未返回具体原因，应明确说明原因不可得。这些仍需登录万相页面手动验证。
- 万相网页视频节点新增“AI 优化”菜单，可选择当前配置的文本模型 API 或本地 Codex；优化只返回文本，审核弹窗可编辑、取消、用原文生成或采用优化稿生成。确认两种来源都保留原提示词与时长/比例等设置，不会在点击“AI 优化”时直接提交视频；未配置文本模型、Codex 未连接或优化失败时应显示原因。测试生成时再按所选提示词调用万相桥接。
- 图片节点的 Codex ImageGen 生成与迭代每次使用独立新 thread，不复用或覆盖助手普通对话的 thread；连续生成至少 4 次（含带参考图迭代）时确认每次走 `thread/start`，图片回填与来源连线正常，之后普通聊天仍恢复原 thread。此调整避免跨轮图片历史累积，本轮附件或单轮多张生成仍可能触及上游请求体限制；助手聊天中临时要求生图不属于此隔离入口。
- 图片节点选择“Codex ImageGen”：不会创建新画布或重复的空生图节点；空图片节点无参考图时按提示词从零生成并填入该节点；已有图片时以原图迭代并新建连接结果，保留原图。
- 图片节点模型列表选择“Codex ImageGen”后，主生成按钮按当前提示词直接生图；“AI 优化”改为独立按钮，只返回文本优化稿，弹窗可查看原文并编辑优化稿，选择“采用并生成”“使用原文生成”或取消。确认优化期间不产生图片、不修改节点内容；取消保留原文，空优化稿不能采用，失败或停止不会自动生图，生成结果保留实际采用的提示词。窄面板中模型、设置和生成控件应换行而不重叠。
- Codex ImageGen 生成期间空图片节点显示“Codex 正在生成”；迭代时保留原图并显示“Codex 正在生成新版本”；成功或失败后状态应清除。失败提示显示可用的具体类型、额度耗尽重置时间，以及 Codex 返回的说明。
- Codex ImageGen 设置面板可配置画幅/尺寸、质量和张数；生成请求会自动带入对应要求，多张时要求逐次调用 ImageGen，迭代结果节点应保留本次设置。验证设置切换会写入节点配置，生成时正确引用；精确像素、质量和张数受 ImageGen 工具限制，可能无法严格保证。
- Codex 参考图在发送前按整轮 3 MiB 图片数据预算压缩，无法读入或压缩到预算内的图片会省略并告知模型；浏览器控制台分别记录画布发往本地 Agent 的 `thread/start`、`thread/resume`、`turn/start` 请求 UTF-8 字节数和图片数据量，不输出提示词或图片内容。复现 413 时核对 F12 中 `[Codex RPC 请求体积]` 的方法、字节数和图片数。
- 收起画布 Agent 侧栏不会中止正在运行的任务；重新展开后任务与状态仍保留。显式停止按钮仍应正常中止任务。
- Fork 的 Docker 发布：合并到 `main` 后确认 GitHub Actions 构建多架构镜像并推送 `ghcr.io/tyreamon/infinite-canvas:latest`；VPS 更新后验证拉取和启动。
