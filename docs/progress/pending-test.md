# 待测试

- 图片节点选择“Codex ImageGen”：不会创建新画布或重复的空生图节点；空图片节点无参考图时按提示词从零生成并填入该节点；已有图片时以原图迭代并新建连接结果，保留原图。
- 图片节点模型列表选择“Codex ImageGen”后，主生成按钮直接调用 Codex；提示词优化默认关闭，关闭时结果节点保留原提示词，开启时才采用 Codex 返回的优化提示词；窄面板中模型、设置和生成控件应换行而不重叠。
- Codex ImageGen 生成期间空图片节点显示“Codex 正在生成”；迭代时保留原图并显示“Codex 正在生成新版本”；成功或失败后状态应清除。失败提示显示可用的具体类型、额度耗尽重置时间，以及 Codex 返回的说明。
- Codex ImageGen 设置面板可配置画幅/尺寸、质量和张数；生成请求会自动带入对应要求，多张时要求逐次调用 ImageGen，迭代结果节点应保留本次设置。验证设置切换会写入节点配置，生成时正确引用；精确像素、质量和张数受 ImageGen 工具限制，可能无法严格保证。
- Fork 的 Docker 发布：合并到 `main` 后确认 GitHub Actions 构建多架构镜像并推送 `ghcr.io/tyreamon/infinite-canvas:latest`；VPS 更新后验证拉取和启动。
