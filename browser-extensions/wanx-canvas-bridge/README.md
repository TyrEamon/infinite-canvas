# 无限画布 × 通义万相桥接扩展

扩展在本机浏览器中暂存桥接数据，不要求部署额外服务器。画布与万相页面需要在同一浏览器中打开；从画布选择“通义万相网页”并点击生成时，扩展会填入提示词和参考素材，并尝试点击万相生成按钮。

## 安装

1. 先按项目说明启动本地画布，默认地址为 `http://localhost:3000`。
2. 在 Chrome 或 Edge 打开扩展管理页，开启“开发者模式”。
3. 选择“加载解压缩的扩展程序”，选中本目录 `browser-extensions/wanx-canvas-bridge`。
4. 打开本地画布项目并刷新页面；再打开 [通义万相视频体验页](https://platform.qianwenai.com/try-ai?scene=video)。
5. 后续更新扩展源码后，在扩展管理页点击此扩展的“重新加载”，再刷新画布和万相标签页。

## 使用

1. 在画布的视频节点模型下拉中选择“通义万相网页”，打开“视频设置”读取万相网页当前模式可选的分辨率、画面比例和时长，再填写提示词并点击画布生成键。未指定的项目保持万相网页当前值；指定项目会在提交前选中并核对，当前网页模式不支持时停止提交并在画布报错。扩展会填入提示词及节点关联的图片、视频、音频素材。
2. 扩展会记录本次万相任务 ID；任务成功且只返回一个视频时，自动下载视频并回传对应画布节点。空视频节点直接填入结果；已有视频节点保留原片，并在旁边创建连接后的结果节点，沿用本轮万相设置便于继续迭代。
3. 如果没有识别到生成按钮、任务 ID 或唯一视频，自动回传会停下并显示原因。万相返回失败状态或只给出文本回复时，画布节点会显示万相返回的说明；若万相只提供笼统拒答，扩展无法进一步判断原因。此时可在万相网页确认结果后，点击扩展图标扫描并手动选择视频；手动列表无法识别任务归属。
4. 也可以继续使用扩展弹窗的“发送到万相”手动桥接；该入口不会自动提交生成。

## 边界

- 当前仅匹配 `localhost:3000`、`127.0.0.1:3000` 和 `platform.qianwenai.com`。
- 单个桥接媒体文件上限为 200 MB；参考素材会按扩展分块暂存。当前一次只支持一个自动桥接任务，任务运行或回传中不会让新任务覆盖它。
- 自动回传依靠打开的万相标签页接收任务进度；生成期间建议保持该标签页开启，关闭页面后可用手动扫描回传。
- 万相页面的 DOM 结构可能调整。若扩展找不到提示词框、上传控件或视频源，需要根据页面实际结构适配；如果浏览器禁止读取视频源，扩展会明确报错，不会伪装成成功。此时可把万相结果页截图发来，不需要先找 F12 网络请求。
- 自动提交依赖万相页面当前可见的生成按钮；任务追踪依赖页面当前的异步任务请求结构。页面更新后可能需要适配。此版本的任务 ID 自动回传尚未经过登录页面端到端验证。
- 画布“视频设置”的分辨率是万相档位，画面比例不是自定义像素尺寸；可选项从已打开的万相视频页读取。切换网页模式后重新打开设置以刷新选项；可选时长会受网页当前模式、账号及输入视频长度限制。找不到或无法确认网页选项时，扩展不会按默认参数继续生成。
