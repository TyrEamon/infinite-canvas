# 无限画布 × 通义万相桥接扩展

扩展在本机浏览器中暂存桥接数据，不要求部署额外服务器。画布与万相页面需要在同一浏览器中打开；从画布选择“通义万相网页”并点击生成时，扩展会填入提示词和参考素材，并尝试点击万相生成按钮。

## 安装

1. 先按项目说明启动本地画布，默认地址为 `http://localhost:3000`。
2. 在 Chrome 或 Edge 打开扩展管理页，开启“开发者模式”。
3. 选择“加载解压缩的扩展程序”，选中本目录 `browser-extensions/wanx-canvas-bridge`。
4. 打开本地画布项目并刷新页面；再打开 [通义万相视频体验页](https://platform.qianwenai.com/try-ai?scene=video)。
5. 后续更新扩展源码后，在扩展管理页点击此扩展的“重新加载”，再刷新画布和万相标签页。

## 使用

1. 在画布的视频节点模型下拉中选择“通义万相网页”，填写提示词并点击画布生成键。扩展会切换到万相视频页，填入提示词和节点关联的图片、视频、音频素材，并尝试提交生成。
2. 如果万相页面结构变化导致扩展无法识别生成按钮，提示词和素材仍会填入页面；请手动检查并点击网页上的生成按钮。
3. 生成完成后，点击扩展图标扫描页面视频并选择结果回传。空视频节点会直接填入结果；已有视频节点会保留原片，并在旁边创建连接后的结果节点。扩展导入实际视频文件，不只保存可能过期的 URL。
4. 也可以继续使用扩展弹窗的“发送到万相”手动桥接；该入口不会自动提交生成。

## 边界

- 当前仅匹配 `localhost:3000`、`127.0.0.1:3000` 和 `platform.qianwenai.com`。
- 单个桥接媒体文件上限为 200 MB；参考素材会按扩展分块暂存，开始新的画布发送时会清空上一轮缓存。
- 万相页面的 DOM 结构可能调整。若扩展找不到提示词框、上传控件或视频源，需要根据页面实际结构适配；如果浏览器禁止读取视频源，扩展会明确报错，不会伪装成成功。此时可把万相结果页截图发来，不需要先找 F12 网络请求。
- 自动提交依赖万相页面当前可见的生成按钮文案或表单结构；页面更新后可能需要适配。此版本尚未经过真实页面端到端验证。
